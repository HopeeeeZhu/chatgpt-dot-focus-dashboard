# 事项选择面板

在面板里看清任务、选一件，再回到原工作对话推进。

> 独立产品交互原型，非 OpenAI 官方项目，与 OpenAI 无隶属或背书关系。本项目不使用 OpenAI 官方标志；ChatGPT、Codex 等名称仅用于说明使用场景，不代表官方兼容或支持承诺。

## 这份 Demo 做什么

用一个可下载的单文件 HTML，展示由粗到细的任务选择：

1. **看总览**：总数、已完成、未完成、待确认。
2. **选处理方式**：专注处理，或随手解决。
3. **按重要性挑一件**：展开卡片，查看下一步、建议步骤和预计投入。

任务全部是合成示例。初始有 10 项，其中 7 项未完成、3 项已完成；4 项待确认包含在未完成中，不重复相加。所有步骤是建议流程，分配日期未知时显示“未记录”。

## 本地预览

下载 [index.html](index.html)，用现代桌面浏览器打开，无需安装依赖或启动服务。仓库中的文件浏览页不等于运行中的交互预览。

页面无远程脚本、字体、图片或接口依赖。当前没有实机预览截图，因此不附看起来像实测结果的示意截图。

## 最短使用路径

1. 点击一个总览计数，缩小状态范围。
2. 选择“专注处理”或“随手解决”。
3. 悬停、键盘聚焦或点开任务行，读下一步与预计时间。
4. 复制操作说明。复制受限时，使用显示的可选文本手动复制。
5. 自行回到你的真实任务对话继续工作。

公开 Demo 没有配置任何真实执行对话链接，不能替你定位或打开某个真实任务。体验可以停在复制，无需把合成事项发送到工作对话。复制本身不会提交消息。

## 怎样减少真实工作中的视觉干扰

进入真实 Codex 任务对话后：

- 先确认 Codex 窗口已获得焦点。
- 若项目侧栏仍可见，macOS 默认按 **⌘B** 收起；已隐藏时无需再按。
- 继续在同一真实对话里输入、讨论和执行。
- 需要时可用 macOS 默认 **⌃⌘F** 全屏。绑定可能被修改，可用 **⌘/** 查看当前快捷键。

这些是需要使用者在真实应用中完成的操作。HTML 不会控制 Codex 的布局、暂停通知、发送消息或同步进度。在浏览器窗口按快捷键，不代表另一个应用已经进入隔离状态。默认快捷键来源见 [参考说明](THIRD_PARTY_NOTICES.md)，目标设备效果仍需实际验证。

## 三个维度分别判断

| 维度 | 取值示例 | 判断依据 |
| --- | --- | --- |
| 紧急性 | 立即 / 可排期 | 真实时限、外部阻塞 |
| 处理方式 | 专注 / 随手 | 注意力需求、预计投入 |
| 重要性 | 高 / 中 / 低 | 影响、阻塞程度 |

高重要性不自动等于立即处理，耗时短也不自动排第一。当前页面**没有独立紧急性字段或筛选控件**；此处提供判断方法，不自动排期。

长期事项先拆成一个小步，写清“动词 + 对象 + 结束条件 + 预计投入”。例如：读一份示例材料，写下 1 个待确认问题，预计 25–40 分钟。完成小步不等于完成整个长期目标。

## 当前能力与边界

已实现三层导航、状态/项目/责任人筛选、卡片展开、本地优先级调整与恢复、建议步骤编辑、说明复制及失败回退、本地演示完成与撤销、保守重置。

- 数据是静态合成快照，不连接真实聊天或任务系统。
- 不监听完成、不后台推送、不自动隔离应用，也不是常驻桌面 App。
- “仅在 Demo 标记完成”只改变本页计数，不确认真实成果。
- 本地设置使用 `localStorage`。下载 HTML 不会把修改写回文件，也不会开启跨设备同步。
- 换浏览器、限制或清理本地存储、改变文件打开位置，可能影响数据保留。不要把本地存储当作备份。
- 分享副本使用独立存储键，不读取私人版笔记或历史任务。
